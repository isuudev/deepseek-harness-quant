# 数据说明

## 数据边界（务必阅读）

**本仓库不包含任何真实行情数据。**

- 行情/财报数据来自第三方数据源（Tushare / akshare / baostock），其使用协议**禁止数据再分发、禁止转售、禁止账号共享**。
- 仓库仅提供数据获取脚本（`data/bulk_loader.py`、`data/incremental_daily_tushare.py`、`data/fetcher_*.py`）；用户自行运行、自行持有数据。
- 开源仓库不附带真实行情，也不附带旧的演示行情库。
- 请遵守各数据源条款；因数据使用产生的任何合规问题由使用者自行负责。

## 数据目录与配置

| 方式 | 优先级 | 说明 |
|---|---|---|
| 环境变量 `LWQUANT_CACHE_DIR` | 1（最高） | 指向数据目录（如 `D:\my_quant_data`） |
| `config/params.yaml` → `data.cache_dir` | 2 | 绝对/相对路径均可 |
| 默认 | 3 | 仓库内 `data/cache` |

核心库（在数据目录下）：

| 文件 | 内容 |
|---|---|
| `bars.db` | 日线（code/date/OHLCV/turn/amount，`adjust='qfq'` 前复权） |
| `stock_basic.db` | 股票列表（含退市股标记） |
| `finance*.db` | 财报（PIT 对齐） |
| `hist_mv.db` | 历史市值 |
| `lhb_full.db` | 龙虎榜 |
| `gdhs_full.db` | 股东户数 |

读取统一走 `data/cache.py`（唯一读取接口，自动合并主库+增量库）。

## 获取数据

```bash
# 股票列表
python data/fetch_stock_basic.py

# 历史日线（baostock，断点续传）
python data/bulk_loader.py

# Tushare 日线增量（需要有效 token）
python data/incremental_daily_tushare.py --basic

# 盘后完整管道
python -X utf8 data/daily_pipeline.py
```

> 数据源预检：`python data/check_data_sources.py`。token 过期时该脚本会给出 `token_expired`，不会打印 token。

- Tushare 需在 [tushare.pro](https://tushare.pro) 注册并获取 token，填入 `config/params.yaml` 的 `data.tushare_token`（120 积分即可覆盖日线+股票列表；更多积分解锁财报/龙虎榜等）
- akshare 免费无需 token（部分接口）
- 数据时间边界：换手率（turn）字段 2019 年起覆盖 90%+；**2019 年前换手率缺失，勿用 2019 前数据做换手类因子结论**

## 数据缺失时

页面保持空态或显示“暂无数据”。禁止用旧日期数据重新生成的页面冒充新交易日数据；以门户「数据日」和 `bars.db` 最新交易日为准。
