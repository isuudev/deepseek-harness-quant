# 快速开始

本文档覆盖：环境准备 → 配置 → 数据 → 启动 → 演示模式 → 一键 EXE。

## 1. 环境准备

- Python **3.10 ~ 3.12**（3.13+ 部分依赖如 vectorbt 可能无法安装；若只跑核心系统，3.13 亦可）
- Windows / Linux / macOS 均可（路径示例以 Windows 为准）

```bash
python -m pip install -r requirements.txt
```

> 最小依赖（仅 Web 系统 + 因子/回测）：`pandas numpy scipy PyYAML akshare requests tqdm`
> 完整依赖（含回测增强）：另加 `baostock tushare backtrader vectorbt quantstats matplotlib`

## 2. 配置

```bash
cp config/params.yaml.example config/params.yaml
```

打开 `config/params.yaml` 填写：

| 配置项 | 说明 |
|---|---|
| `data.cache_dir` | 数据目录（SQLite/Parquet 存放处）。留空则默认 `data/cache`；也可用环境变量 `LWQUANT_CACHE_DIR` 覆盖（优先级最高） |
| `data.tushare_token` | Tushare 积分账号 token（**数据获取才需要**，见数据说明） |
| 其余策略参数 | 均为阈值/权重，保持默认即可；改参数不改代码 |

## 3. 获取数据

```bash
# 1) 股票基础信息（baostock）
python data/fetch_stock_basic.py

# 2) 历史日线全量/断点续传（baostock，首次较慢）
python data/bulk_loader.py

# 3) 财报等 Tushare 数据（按需）
python data/fetcher_finance.py
```

- 每日盘后完整更新：`python -X utf8 data/daily_pipeline.py`
- 先检查 token：`python data/check_data_sources.py`
- 详细说明见 [数据说明](数据说明.md)

## 4. 启动

```bash
python deck/deck_server.py
```

浏览器打开 **http://127.0.0.1:8787**（门户）。

常用页面：

| 路径 | 页面 |
|---|---|
| `/` | 门户（KPI + 择时 + 实时信息） |
| `/pitch` | 决策（Pitch 候选卡 + 审批） |
| `/holdings` | 持仓 |
| `/factors` | 因子池 |
| `/backtest` | 回测归档 |
| `/etf` | ETF 映射（策略暴露 → ETF 相关性/配置） |
| `/pitchtrack` | 主观多池远期（五池对比 + 牛散决策者分组） |
| `/control` | 控制台（系统状态；「控制/HARNESS 对话」需另装 DeepSeek HARNESS，未装则显示未连接） |

## 5. 无真实数据时

当前开源仓库不附带演示行情库。没有真实数据时，页面会显示“暂无数据”，不要根据空页面做交易判断。先完成 Tushare/akshare 数据接入。

## 6. 一键 EXE（Windows）

仓库 `dist/QuantDeck.exe`（或自行打包，见下文）：

- 双击即启动服务（127.0.0.1:8787）并自动打开浏览器
- EXE 不含 akshare 数据拉取能力（体积/稳定性考虑）——数据获取请使用 Python 环境
- EXE 同目录需有 `data/`（数据目录）；也可设置系统环境变量 `LWQUANT_CACHE_DIR` 指向数据位置

### 自行打包 EXE

```bash
python -m pip install pyinstaller
python scripts/build_exe.py
# 产物: dist/QuantDeck.exe
```
